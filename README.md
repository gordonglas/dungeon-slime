# Monogame - Dungeon Slime tutorial

This repo follows along with the [Monogame Dungeon Slime tutorial](https://docs.monogame.net/articles/tutorials/building_2d_games/) while my son and I learn Monogame.

While there are other tools/OSes you can use, I happen to be using VSCode in Windows 11 while I work through the tutorial, and I have the .NET 10 SDK installed.

One slight deviation from the Tutorial I made was when running the game for the first time in Chapter 2 of the tutorial, I had to select `.slnx` instead of `.sln`, because `.sln` didn't properly put the project path in the `.sln` file, while choosing `.slnx` does. I don't know yet if there will be any side-effects of using .slnx instead .sln later on in the tutorial, but it's working so far.
