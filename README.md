# Monogame - Dungeon Slime tutorial

This repo follows the [Monogame Dungeon Slime tutorial](https://docs.monogame.net/articles/tutorials/building_2d_games/) while I learned Monogame. It is complete.

While there are other tools and operating systems you can use, I happened to use `VS Code` in `Windows 11` while working through the tutorial, and I have the `.NET 10 SDK` installed.

One slight deviation I made from the tutorial was when running the game for the first time in Chapter 2. I had to select `.slnx` instead of `.sln` because `.sln` didn't properly include the project path in the solution file, whereas `.slnx` did. This didn't cause any problems.

If you want to play the game, you can download the official tutorial's build of [Dungeon Slime on itch.io](https://monogame.itch.io/dungeon-slime). I didn't feel it was necessary to duplicate the release here.

I also wanted to add that I was really impressed by this tutorial. It covers a wide range of 2D game development concepts, follows best practices, and demonstrates good organization that is easy to follow and learn from. Highly recommended.
